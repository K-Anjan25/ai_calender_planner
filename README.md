Plan your week, adjust your working hours, and export your schedule. Google Calendar publishing requires your approval.

## Run locally

```bash
npm install
npm run dev
```

Open **http://localhost:3000**. No API keys are needed to try the planner.
For Google sign-in, Calendar, or an AI provider, copy `.env.example` to `.env.local` and configure the services you need.

## Check

```bash
npm test
npm run build
```
